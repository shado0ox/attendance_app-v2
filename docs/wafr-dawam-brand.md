# وفر دوام | WAFR Dawam

تم تطبيق الشعار في الدخول وشريط الإدارة وبوابة الموظف وتثبيت التطبيق، مع الاحتفاظ باسم الشركة وشعارها وصورة الموظف كبيانات مستقلة عن هوية المنتج.

الألوان: كحلي #102C3A، تركواز #16B8A6، أزرار #087F73، خلفية #F4F8F7. ملفات الشعار SVG تحتوي مسارات للحروف ولا تحتاج خطًا خارجيًا.

أيقونات PWA العادية 192 و512، وMaskable بمساحة أمان، وآيفون 180، ومتصفح SVG/ICO/16/32. تحديث ملفات الأيقونات القديمة في مكانها يضمن أن الإشعارات ومراجع التطبيقات القديمة تستخدم الهوية الجديدة أيضًا.

اسم المنتج في ملفات manifest والعنوان ورسائل البريد وصفحة الخصوصية. start_url وscope ومسار manifest ومفاتيح التخزين وتعريفات WebAuthn ثابتة للحفاظ على التطبيق المثبت والحسابات. اختيار الاسم/الأيقونة على الشاشة الرئيسية للأجهزة المثبتة مسبقًا يخضع لتحديث نظام الهاتف ولا يمكن فرضه من الموقع.

لا تغيير لاسم قاعدة البيانات أو المخطط أو Docker أو أسماء الجداول أو بيانات الشركات. لا توجد migrations أو عمليات إعادة تسمية للبيانات.
