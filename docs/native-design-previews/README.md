# معاينة المكونات الأصلية

صور مراجعة للشاشات الفعلية عبر محولات React Native Web المعزولة في `mobile/tests/visual/`، ببيانات اصطناعية لا تتصل بسيرفر الإنتاج. لا تمثل موظفًا أو شركة حقيقية. الأيقونة الحرفية بديل عند عدم توافر شعار أو صورة؛ التطبيق يعرض صور الشركة والموظف المحفوظة عند وجودها.

- `home-working.png`: العمل، الحلقة وملخص الفترة.
- `home-break.png`: الاستراحة وتأخر الرجوع.
- `checkout-receipt.png`: الإيصال بعد تأكيد السيرفر.
- `settings.png`: إعدادات الموظف المنفصلة.

الشريط السفلي تمثيل لمساحة NativeTabs، والحركة ثابتة في العارض. فحص الأجهزة الأصلية منفصل عن هذه الصور. الصور تعرض جزء الشاشة المرئي؛ بقية المحتوى متاح بالتمرير.

تحديث الافتتاح والإعدادات:
- `launch.png`: إطار ثابت من شعار الافتتاح. رسم SVG متحرك في التطبيق؛ محول الصور لا ينفذ حركة Reanimated الأصلية.
- `location.png`: تعليمات الموقع المبسطة دون شرح المحاكي في Release.
- `notifications.png`: رسالة عدم إتاحة التذكيرات دون تفاصيل إعداد الخادم.
