# إدارة الموظفين والأقسام

شؤون الموظفين أصبحت قائمة تحتوي على البحث بالاسم/المستخدم/البريد/الجوال، وفلتر القسم، وفلتر البريد الناقص، والفرز بالاسم أو القسم، وتقسيم القائمة إلى صفحات من 20 موظفًا. البحث والفلاتر والصفحات محلية لا تنشئ طلبات سيرفر إضافية.

تحديد الصفوف ثم اختيار القسم الجديد ينقل الموظفين المحددين بعد التأكيد، ويحفظ مرة واحدة عبر الحفظ المتزامن الموجود. تغييرات الفلاتر تلغي التحديد. النقل يعدّل قسم الموظف فقط ولا يغيّر الجداول المحفوظة. لا يسمح بحذف قسم له موظفون؛ انقلهم أولًا. رموز الدخول مخفية افتراضيًا ويمكن للمسؤول إظهارها عند الحاجة.

من تعديل القسم اختر اللون وارفع شعار PNG/JPEG/WebP لا يتجاوز 2MB. تُصغّر الصورة إلى 128px قبل حفظها. بدون صورة يظهر شعار تلقائي من أول حروف اسم القسم. العرض يقبل صور raster مضمّنة محدودة الحجم فقط.

عند فتح بوابة الموظف بدون بريد صحيح تظهر نافذة تطلب البريد. يمكن تأجيلها والاستمرار في البصمة والجدول مع رابط لإضافة البريد. بعد الحفظ يُخزّن البريد في بيانات الموظف بقاعدة البيانات، ويُحدّث الجدول مرة واحدة، ولا يتكرر الطلب عند الفتح القادم إذا كان البريد محفوظًا. البريد لم يخضع للتحقق برسالة تأكيد ولا يغيّر طريقة الدخول، ولا يرسل ترحيبًا تلقائيًا؛ الإدارة تستطيع إرساله من قائمة الموظفين.

المسار PATCH /api/employee-profile/email يسمح للموظف بتعديل بريده فقط، وفق هوية الجلسة والشركة، ويتجاهل empId وكلمة المرور والجدول وأي حقول إضافية. قفل صف بيانات الشركة أثناء الحفظ يحافظ على أحدث البيانات، وتعديل البريد يغيّر إصدار البيانات لمنع مسؤول يحمل نسخة قديمة من الكتابة فوقه.
