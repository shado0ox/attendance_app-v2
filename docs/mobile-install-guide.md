# تنزيل التطبيق أعلى الصفحة وزر Get

استبدال تنبيه التثبيت العائم القديم بشريط خفيف أعلى الصفحة، وفق النموذج المرجعي: زر Get يسارًا، وأيقونة وفر دوام واسمه ووصف قصير وزر إغلاق يمينًا. الشريط جزء من التدفق الطبيعي للصفحة (ليس fixed أو overlay)، فلا يغطي الهيدر أو أي محتوى تحته. يمكن إغلاق الشريط مع بقاء زر Get الصغير الثابت أسفل الصفحة، وفوق تنقل الموظف على الجوال. مخفي عند طباعة الصفحة وعلى صفحات توقيع المدير.

الضغط يفتح نافذة حوار صغيرة بها ثلاثة رسوم مصغرة محلية ورموز وخطوات بالعربية. يختار نوع الجهاز تلقائيًا، ويدعم iPad الذي يعرض نفسه كـ Macintosh؛ ويمكن تبديل الدليل يدويًا.

- iPhone / iPad: فتح الرابط في Safari، ثم مشاركة (مباشرة أو عبر قائمة الصفحة)، ثم إضافة إلى الشاشة الرئيسية وتفعيل فتح كتطبيق ويب إن ظهر ثم إضافة.
- Android: Chrome ثم ⋮ ثم التثبيت وإنشاء اختصار/تثبيت أو الإضافة للشاشة الرئيسية حسب إصدار المتصفح. زر «تثبيت الآن من المتصفح» يظهر فقط عند توفر beforeinstallprompt، ويستخدم الإذن بعد ضغط المستخدم ولمرة واحدة. إلغاء الطلب لا يخفي دليل التثبيت.
- الرسوم توضيحية وليست صورًا ملتقطة من جهاز المستخدم. الموقع والإشعارات يطلبهما التدفق الحالي داخل التطبيق؛ التثبيت لا يضمن GPS في الخلفية.

يعتمد إخفاء الشريط والزر على وضع العرض standalone/fullscreen/minimal-ui وnavigator.standalone وحدث appinstalled، ولا يخفيهما لمجرد قبول طلب التثبيت. إغلاق الشريط وحده لا يغلق الزر الثابت. نافذة HTML dialog تدعم Escape وإغلاق النافذة وإعادة التركيز للزر، وتُمرّر محتواها على الشاشات الصغيرة.

## روابط المتاجر لاحقًا

مسؤول المنصة وحده يضبط الروابط في «الإعدادات ← تنزيل التطبيق وروابط المتاجر». الإعداد موحد لجميع الشركات وصفحة الدخول؛ الشركات الأخرى لا تستطيع تعديله. يتاح GET `/api/app-installation` للعامة ويعيد الرابطين فقط، وPOST لمسؤول المنصة. تُقبل روابط HTTPS لتطبيقات apps.apple.com وplay.google.com/store/apps/details فقط، دون حساب داخل الرابط أو منافذ مختلفة أو مخططات JavaScript.

الروابط فارغة افتراضيًا. عندما يضاف رابط المنصة المناسبة، ينتقل زر Get مباشرة إلى App Store على iPhone / iPad أو Google Play على Android. منصة بلا رابط تظل تعرض شرح التثبيت، والكمبيوتر يعرض الدليل واختيار المنصة. حذف الروابط يعيد الشرح. حفظ الإعداد يحدث المدخلات في المتصفح نفسه، والزائر الجديد يجلب الروابط عند فتح الصفحة. لا توجد روابط تجريبية أو ادعاء بأن التطبيق منشور قبل توفير رابطه الحقيقي.

مصادر خطوات التثبيت:
- https://support.apple.com/en-lamr/guide/iphone/iphea86e5236/ios
- https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid

التحقق: اختبارات تحديد الجهاز وحصر روابط المتاجر، اختبار API وصلاحياته على PostgreSQL، واختبارات متصفح لموضع الشريط وعدم تغطية المحتوى والصور والزر الثابت وEscape وإلغاء التثبيت وتوجيه المتجر وإخفاء المداخل بعد التثبيت.
